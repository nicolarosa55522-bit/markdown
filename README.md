**como funciona o markdown**

*o markdown funciona usando de duas syntax*

I. syntax basica
- Estes são os elementos descritos no documento de design original de John Gruber. Todos os aplicativos Markdown oferecem suporte a esses elementos.
  
II. syntax externa
- Estes elementos estendem a sintaxe básica ao adicionar recursos extras. Nem todos os aplicativos Markdown oferecem suporte a esses elementos.
